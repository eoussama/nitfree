### Single purpose

Keep a personal library of emojis, stickers and GIFs in the browser and send them in Discord at the right size.

### Permissions

| Permission                  | Why                                                                                   |
| --------------------------- | ------------------------------------------------------------------------------------- |
| `storage`                   | Saves settings and the last Discord theme seen, so the popup matches it.              |
| Host access to `discord.com` | Adds the Nitfree button and panel to Discord and reads its theme colors. No other site is touched. |

### Data and privacy

- Nitfree collects no data. Everything stays in the browser: no account, no server, no analytics, no network calls of its own.
- No remote code is loaded; every script ships in the package.
- Chrome data usage form: no category of user data is collected. Firefox: `data_collection_permissions` is `none`.
